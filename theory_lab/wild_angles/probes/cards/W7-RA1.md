# W7-RA1 — The 132 as a forced monochromatic core (Gallai / Hales–Jewett)   ·   VERDICT: KILLED

**Card claim:** 2-color the bit×slot carry grid; ~132 grid cells are color-FROZEN across (almost) all messages = the unavoidable monochromatic core, with the hard-core output bits downstream of it; HW~74 = its density.

**Probe run:** N=4,6,8,10,12. Extracted the full carry matrix over all 64 rounds (carry-in of every modular add: c[j] = sum[j] XOR (XOR of addend bits j); 7 carry slots/round = h+S1, +Ch, +K, +W, T2, d+T1, T1+T2). Sampled 500–600 random messages per N, found FROZEN cells (carry bit constant across the sample), and measured count-scaling + contiguity. Refinement (`_ra1_refine.py`) strips trivial freezes and tests for a STABLE basis-independent core. Throttled.

**Result (numbers):** Raw frozen carry cells = 520, 530, 537, 548, 553 (N=4..12) — nowhere near 132, and GROWING with N (linear fit ≈4.2·N + 504). Of these, exactly 448 are the LSB column (bit 0 has no carry-in EVER — pure arithmetic triviality, = 64×7). Survivors after stripping bit-0: 72→82→89→100→105 (still grows with N). The growth is all in early rounds (≤15): 29→60 (finite-size / IV-propagation freezes). The only N-stable component (rounds >15) is 45 cells — flat across N but ≠132, dominated by the `T1_3` (+K) slot at low bits (1,2), i.e. frozen because K is a fixed constant. Contiguity of real survivors (LSB line removed) neighbor_frac = 0.35–0.40 (scattered, no 2D block) across all 5 N.

**Kill_criterion:** "frozen count grows like the FULL grid area, OR frozen cells are SCATTERED (no line geometry) across ≥3 N." — **fired? yes (both prongs).** Frozen count grows with N (not a fixed 132; floor = trivial LSB column + finite-size early freezes), AND the genuine stable survivors are scattered (neighbor_frac ≈0.37, mostly a single bit-column in the +K slot) across all 5 N.

**Verdict reasoning:** There is no stable 132. The number splits into three non-Ramsey pieces: (i) 448 = "no carry into the LSB" (arithmetic triviality), (ii) a width-scaling early-round residue (29→60, finite-size propagation, exactly the skeptic's non-forcing regime), (iii) ~45 stable cells that are a fixed-constant-K artifact (carry from +K biased at low bits), not a monochromatic combinatorial core and not contiguous. Per finding #1 this is the 132-as-census category error in a new disguise: the 132 hard-core is the deterministic-control census {a,b,e,f}@63 + 4dc = 4N+4 (width-scaling), never a basis-independent invariant — and the carry-frozen count here likewise resolves into trivialities + width-scaling + K-constant bias, never a stable 132 with line geometry. No CONFIRM without a stable basis-independent object; none exists.

**Cross-check / skeptic note:** What would overturn KILLED: a frozen set of fixed size ~132, the SAME (round,slot,bit) cells across N, forming a contiguous sub-grid/line, and not explained by LSB/K-constant/IV-propagation. Found the opposite on every axis. Independent corroboration: the stable late survivors localize to the +K carry slot (a constant-K effect), and the count's N-dependence (72→105) is the signature of width-scaling, not a Ramsey invariant.
