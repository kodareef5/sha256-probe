## Interpretation

The first sparse-M2 attempt did not improve the F802 HW85 branch. With
M2-popcount penalty 0.5, the best objective remained the initial HW85 state and
no lower-HW state appeared.

This does not kill the sparse coordinate globally. It says this particular
F802 HW85 point is locally closed under HW, target-lane, and target-sparse
pair beams. The next sparse test should start earlier in the branch, before
the M2 mask grows to weight 56.
