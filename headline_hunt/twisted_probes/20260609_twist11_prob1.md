# Twist 11 — Mapping SHA-256's probability-1 (deterministic) differential structure

## Question
For an input STATE difference (message schedule W common across the pair), the
output state difference is generally **probabilistic**: it depends on the
absolute base values through carries (modular add) and through the
data-dependent booleans Ch/Maj. This twist isolates the **deterministic
(probability-1)** part — the output-difference bits that are CONSTANT across all
random bases. That prob-1 set is exactly the differential structure an attacker
gets "for free," with no probabilistic conditions to satisfy via message
modification. We map it over all 256 single-bit input differences x R=1,2,3,
profile determinism by bit position (the MSB channel), and search for the
maximal prob-1 differential.

Method: for a fixed input difference `delta`, run R rounds of the verified round
function `fwd` (reused exactly from `fresh_batch.py`) on a random base state
`s1` and on `s1 ^ delta`, with a common random schedule W. An output-diff bit is
**prob-1** if it is the same value (always 0 or always 1) across all Ksamp draws.
We split prob-1 into **const-0** (bit never differs — either untouched or always
cancels) and **const-1** (bit always FLIPS — the genuinely informative "free"
flipped structure). Fully deterministic / seeded. Ksamp = 2000–4000.

## Part 1 — Per-output-bit determinism, all 256 input diffs, R = 1,2,3

Mean prob-1 output bits over all 256 single-bit input differences (out of 256):

| R | mean prob-1 /256 | % deterministic | mean const-1 (flipped) |
|---|------------------|-----------------|------------------------|
| 1 | 236.2 | **92.3 %** | 1.64 |
| 2 | 184.9 | 72.2 % | 1.89 |
| 3 | 127.9 | **50.0 %** | 1.81 |

At R=1 the round function is **92 % deterministic** at the bit level for a
single-bit input difference — almost all output bits are forced. This decays
geometrically: ~92 % -> ~72 % -> ~50 % per added round, hitting the ~50 % (full
randomization) floor by R=3. The "free" structure is overwhelmingly a **one-round**
phenomenon.

Per-input-bit extremes (R=1):
- Most deterministic: `h[31]`, `d[31]` = **256/256** (fully deterministic output),
  then `c[31]`, `b[31]`, `d[30]` = 255/256.
- Least deterministic: register **e** low/mid bits — `e[11]`=194, `e[0]`=196,
  `e[12]`=196 (out of 256). e is the most "active" register: it feeds Sigma1
  (3 rotations) and Ch simultaneously, so a low-e difference fans out into many
  carry- and data-dependent positions.

## Part 2 — The MSB channel (determinism vs bit position)

Mean prob-1 output bits at R=1, averaged over all 8 registers, by input bit
position:

| input bit position | mean prob-1 /256 |
|--------------------|------------------|
| MSB (bit 31)       | **247.0** |
| mid (bit 15)       | 232.0 |
| low (bit 0)        | 231.5 |

The MSB channel is real and measurable: an MSB input difference is ~6–7 % more
deterministic at the output than a mid/low difference. **Every** register shows
the MSB edge (MSB prob-1 >= non-MSB mean for all 8). The cleanest channels:

- `d[31]` and `h[31]`: **256/256 deterministic** — a *single unique* output
  difference over 5000 bases (verified directly): `d[31] -> e=0x80000000` and
  `h[31] -> {a,e}=0x80000000`. The difference enters via the additive
  `T1`/`d+T1` path at bit 31, where XOR == modular add (no carry-out) and there
  is no rotation neighbor above bit 31, so it propagates with zero probabilistic
  conditions.
- `b[31]`, `c[31]`: 255/256 — only a single data-dependent bit (the Maj term
  introduces exactly **2** distinct outcomes over 5000 bases for `b[31]`).
- `e[31]`: weakest MSB (211/256) — even at the top bit, e's triple-rotation
  Sigma1 fan-out (bits 6,11,25 wrap the difference to non-MSB positions) plus Ch
  inject probabilistic bits.

**Mechanism confirmed directly** (5000-base exhaustive distinct-output count):
`d[31]` -> 1 outcome, `h[31]` -> 1 outcome, `b[31]` -> 2 outcomes,
`e[0]` -> **3682** outcomes. Determinism is governed by (i) whether the input
difference avoids carry-out (MSB does), and (ii) how much Sigma/Ch/Maj fan-out
it triggers (the additive d/h paths trigger none on round 1; e triggers the most).

### Deterministic corridor — survival across rounds
"Full determinism" (all 256 output bits prob-1) is extremely short-lived. Scanning
all single-bit inputs, the **longest** full-output determinism survival is
R = 1 (achieved by `d[31]` and `h[31]`); by R = 2 even these drop to
212/256 and 209/256. There is **no multi-round deterministic corridor** for a
single-bit state difference: the corridor is exactly one round wide. The MSB
gives a strong *one-round* head start, not a persistent channel.

## Part 3 — Maximal prob-1 differential

Searched single bits, all MSB-subset patterns {a..h}[31] up to size 3 (+ all-8),
and small MSB-adjacent combos. Most-deterministic 1-round differentials
(prob-1 /256, Ksamp=4000):

| input difference | prob-1 /256 | const-1 (flipped) |
|------------------|-------------|-------------------|
| MSB{f,g}         | **256** | 4 |
| MSB{d,f,g}       | 256 | 3 |
| h[31]            | 256 | 2 |
| MSB{f,g,h}       | 256 | 2 |
| d[31]            | 256 | 1 |
| MSB{d,h}         | 256 | 1 |

Several inputs reach **fully deterministic (256/256)** 1-round output. The
winner by flipped-bit count is **MSB{f,g}** (f[31]+g[31]): a fully
deterministic output with **4** deterministically-flipped output bits — the
largest "free flipped" structure found. (f and g enter only through Ch at bit 31
where the difference cancels into a fixed pattern, plus the copy paths f->g,
g->h, all carry-free at the MSB.)

### How long does the winner's determinism survive?
`MSB{f,g}` across rounds:

| R | prob-1 /256 | % deterministic |
|---|-------------|-----------------|
| 1 | 256 | 100 % |
| 2 | 206 | 80.5 % |
| 3 | 144 | 56.2 % |
| 4 |  82 | 32.0 % |
| 5 |  15 |  5.9 % |
| 6 |   0 |  0.0 % |

Full determinism survives **exactly 1 round**; *any* determinism is essentially
gone by **R = 6** (0/256). The decay is geometric and matches the Part-1
population trend. No prob-1 differential — single-bit, MSB-pattern, or small
combo — survives past round 5.

## Verdict
SHA-256's round function has a **large but shallow** prob-1 corridor. "Large":
~92 % of output-diff bits are deterministic at R=1 for a single-bit input, and
several MSB differences (d[31], h[31], MSB{f,g}, ...) give a *fully* deterministic
1-round output. "Shallow": that determinism collapses geometrically
(92 % -> 72 % -> 50 % over R=1,2,3) and is gone by R≈6. There is **no
multi-round deterministic corridor** — the full-determinism window is exactly
**one round wide** for any state difference tested.

This precisely **re-derives why MSB kernels are used** (as the task anticipated),
and quantifies it: the MSB channel buys a ~6–7 % determinism premium at R=1 and,
for the additive-path registers (d, h) and the Ch-cancellation pair (f, g), a
clean carry-free, fan-out-free entry that is fully deterministic for one round.
The mechanism is exactly: (1) XOR == modular add at bit 31 (no carry-out),
(2) no rotation neighbor above the MSB, (3) registers reached by pure copy/add
(b,c,d) or by Ch/Maj cancellation contribute zero new probabilistic bits on the
first round. e is the anti-channel (triple-rotation Sigma1 + Ch fan-out).

**Honest assessment:** this is the *expected, healthy* picture for a strong
compression function — abundant single-round determinism (which is why
1–2 round message modification is cheap and standard) but no deterministic
structure that survives even a handful of rounds. The "free" differential
budget is real but one-round-deep; it is consumed entirely within the first
1–2 rounds of any characteristic and provides no leverage over the dozens of
rounds where SHA-256 is unbroken. **Not a new weakness** — a precise
quantification of the standing MSB-kernel rationale.

### What would change the assessment
- A state difference whose output stays **fully deterministic past R=1**
  (a genuine multi-round prob-1 corridor). None found; window is exactly 1 round.
- A prob-1 differential with **many** const-1 (flipped) output bits that persists
  (would be an exploitable free characteristic). Best was 4 flipped bits at R=1,
  gone by R=6.
- Coupling state-difference determinism with **message-schedule difference
  freedom** (this probe holds W common). Carry-free MSB differences in W might
  extend the corridor — the only avenue where "deterministic + multi-round"
  could plausibly meet, and the natural follow-up.
